Custom Direction Maps
Track Direction Map edit is no longer accessible from Step Mode. As per legacy operation it
remains available from Track Mode via double-click of the track DIR selector.

Step 'Mask' value
Certain features reference a new Step 'mask' value, this value is used to prevent an action being
applied to a specified step. The Step AMT attribute value of -127 is the 'mask' value.
Step Mask is available in the following functions:-
Effector Step Mask - Page 63
Step Event Track Toggle Rotate - Page 38
