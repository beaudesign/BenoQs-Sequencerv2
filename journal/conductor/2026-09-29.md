## 2026-09-29, PR 5 (octorun)

**Intend to change:** Give the sequencer a way to run without a host (O7): a pattern file in,
a byte-reproducible event log and a Standard MIDI File out, golden hashes for five patterns,
and a determinism gate that fails when the engine plays one of them differently.
**How I'll know it worked:** `just run examples/hello` prints the same two hashes every time,
the golden tests fail when a hash is changed by one digit, the engine compiled to WebAssembly
writes the identical log, and `cargo xtask verify --base` exits 0 with the new gate passing.

### What I did

- `crates/octorun`: no dependencies. SHA-256, the NDJSON log, a format-1 MIDI file writer
  with a tempo map and one track per port, and the `octorun` binary.
- `octocore::fixture::run_script` returns everything a script rendered, with ceilings so a typo
  is an error and not an out-of-memory. DSL v3 gained `dir` and `grv`. Filed as a request to Metronome.
- Five example patterns and their goldens. `just run`, `just golden`, `just wasm-smoke`.
- The `determinism` gate in xtask, required from now on.
- `harness/wasm/smoke.mjs` and a CI job for it.

### What surprised me

- **The WASM check worked on the first run.** The engine compiles to a module with no imports,
  and all it needed was to know that wasm32 passes structs by pointer. Same hashes as native.
- **My first mutation test tested nothing.** I changed the first hash digit to 0 in a file whose
  hash already started with 0. The check passed, correctly, because nothing had changed. Redone
  on a hash that starts with 8.
- **Renaming a test is a deletion to the ratchet.** I renamed two xtask tests to match a new
  count of wired gates and the baseline would have lost two names. Reverted the names and left
  a comment. The ratchet does what it was built to do.
- **The engine fires the first step on tick 12 of a pattern, not tick 1.** Visible in every
  golden: the first NoteOn of `hello` is at sample 1375. Already logged as an open finding.

### Blocked or open

- Live MIDI through `midir`: needs the dependency decision and a device.
- The FFI cannot program phrases or MCC yet, so 2 of 5 patterns skip in the WASM check.
- The CI jobs have never run on GitHub.
