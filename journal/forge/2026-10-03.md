### What I learned and what surprised me
- A saved file from the page had no commit at all (only the runner's simulated files do), so until now a real-port file could not say which engine it
  was a run of. The hash is computed from the bytes the page fetched, so it names the module that ran and not the one on disk later.
- The hash needs SubtleCrypto, which a page has only from a secure context. `localhost` is one; a page opened by a LAN address is not, and the report says
  "not computed" with the reason and keeps the size and ABI number. ABLETON.md says to serve it from `localhost`.
- The node_modules symlink in the worktree is untracked (the ignore line is for a directory), so the simulated runner's "uncommitted changes in apps/web"
