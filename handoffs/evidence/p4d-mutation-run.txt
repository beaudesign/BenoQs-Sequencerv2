# What survived, and why it is left:
#  [23] "a stall does not retake the anchor" and [24] "never gives up counting whole pulses" each guard the same thing as the other and as the
#       anchor taken from the engine's own position: a count that cannot be trusted is taken again as the nearest whole pulse. Any one alone
#       is covered by the other two, so removing one is not seen; REMOVING TWO TOGETHER IS: [33] and [34] are caught. The three are
#       redundant on purpose and are kept.
#  [30] "position used while stopped": the follower reads the engine's position only while it believes the transport is running, and drops
#       the early return that says so. EQUIVALENT: while stopped the anchor is null and the same function then takes the nearest whole
#       pulse, writes a phase that status() does not show (it reports null while stopped) and sends a tempo equal to the sender's,
#       which is what is sent anyway. Nothing observable differs. Left as it is, and named so nobody mistakes it for a gap in the tests.
#
