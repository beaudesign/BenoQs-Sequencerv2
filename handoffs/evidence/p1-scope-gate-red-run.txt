## A bug this run found in the gate itself

The first run reported 218 hits, 51 of them under specs/SPEC-0001/ and specs/SPEC-0002/, both on the
allow-list. The allow-list had been lowercased along with the phrases, so `specs/SPEC-0001/`
no longer matched `specs/SPEC-0001/README.md`. Fixed with `parse_allow`, which keeps case, and
pinned by `scope::tests::the_allow_list_keeps_the_case_of_a_path` and an assertion in
`the_real_lists_meet_the_floor_and_the_allow_list_covers_its_own_files`.
