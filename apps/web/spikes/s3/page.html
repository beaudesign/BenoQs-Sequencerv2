Spike S3: the MIDI clock with Ableton Live

WENGE P4 (SPEC-0002, WENGE-0015). Two runs, on real MIDI ports. Follow listens on one input for a clock that Live sends and steers the real engine with it, as the app does in its Slave state, and records how far the engine is from where the sender's clock says it should be. Send makes the engine the clock master, sends its clock to one output, and listens on one input for it to come back through a loopback port (macOS: the IAC Driver; Windows: loopMIDI), which needs no Live. The steps for Live are in apps/web/ABLETON.md.

Keep this tab in front for the run the plan asks for (30 minutes at 120 BPM). A second run with the tab behind another is worth having: the result records how long the tab was hidden and reads the two cases apart.

Follow a clock

Start this run first, then press Play in Live: the engine starts on the Start message, and a clock alone does not start it.

Send a clock

Choose an output and an input that are the two ends of a loopback port. Do not choose a port that goes to a synth or to Live: the run sends a clock for as long as you choose.
