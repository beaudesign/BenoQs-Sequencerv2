# Evidence for handoff records

The handoff records in `handoffs/*.ndjson` cite red runs (a test failing on the parent
commit) and mutation checks. The first PR series cited them as `scratchpad/<name>.txt`,
which is a scratch directory that does not survive the session. The files are kept here
under the same names, so a reviewer can read them.

| File | Cited by | What it shows |
|---|---|---|
| `pr3-red-run.txt` | WENGE-0001, WENGE-0002 | The transport invariants failing on the unchanged engine (6 of 8 fail). |
| `pr4-o3-red-run.txt` | WENGE-0003 | The buffer-size invariance test failing on `e04d9ba`: 192 of 192 (seed, buffer) pairs differ. |
| `pr4-o5-red-run.txt` | WENGE-0005 | The defer, pair and tempo tests failing on `4ddc300`. |
| `pr4-o10-red-run.txt` | WENGE-0010 | The ordering, velocity 0 and MCC tests failing on `586ebaa`. |
| `probe-pr4.txt` | WENGE-0003, WENGE-0005 | The timing and allocation probe output. The probe itself is not in the repo. |
| `pr5-golden-mutation.txt` | WENGE-0007 | One hex digit changed in a golden hash makes `golden::hello` fail. |
| `pr5-wasm-mutation.txt` | WENGE-0007 | The same change makes the WASM smoke test exit 1. |
| `pr5-review-fix-gate-exit.txt` | review of PR 5 | `xtask gate determinism` exited 42 and now runs the gate. |
| `pr5-review-fix-smf-tempo.txt` | review of PR 5 | A tempo below 3.58 BPM was truncated in the SMF tempo event, and is now refused. |

These are captured terminal output, not generated by the build. They are evidence for a
human reading a review, not a gate. Do not edit them; add a new file for a new run.
