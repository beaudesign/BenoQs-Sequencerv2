## What I learned

- The cleanest hook is not "remember the notes" but "remember the seed": a cell of the tape starts a small generator that
  does the existing draw unchanged. The step's notes are then a pure function of its cell, the Octopus's own code path is
  reused, and the without-replacement rule needs no new case (an earlier design that stored raw picks could hang on a
  repeated value).
- `TrackAttr` is mirrored in `crates/octoffi/octoffi.h`, so adding a value there is a contract change. A setter that
  only the web build has avoids it.
